# 包的使用

- 日期：2026-08-14
- 阶段：Java 基础
- 状态：新学

## 学习目标

- 理解包（package）的作用
- 掌握包声明与目录结构的对应关系
- 能创建带包的程序，并用命令行编译、运行

## 核心概念

### 什么是包

包是用来组织类和接口的命名空间。它解决两个问题：一是把功能相关的类放在一起，二是避免不同模块里的类同名冲突。

### package 声明

`package` 必须写在 Java 文件的第一行（注释可以放在前面），例如：

```java
package com.example.calculator;
```

声明之后，这个文件里的所有类都属于该包。

### 包名与目录

包名中的点号对应目录层级。`com.example.calculator` 表示类文件要放在 `com/example/calculator/` 目录下。

### import

如果要在其他包中使用某个类，需要用 `import` 引入，例如：

```java
import com.example.calculator.Calculator;
```

同一个包内的类可以直接使用，不需要 `import`。

### 命名规范

- 包名全部使用小写字母
- 用域名反写作为前缀，例如 `com.example`
- 中间用点号分层，每一层含义清晰
- 不要使用中文或包含空格的包名

## 代码示例

创建如下目录结构：

```text
项目根目录/
└── com/example/calculator/
    ├── Calculator.java
    └── Run.java
```

Calculator.java：

```java
package com.example.calculator;

public class Calculator {
    public int add(int a, int b) {
        return a + b;
    }
}
```

Run.java：

```java
package com.example.calculator;

public class Run {
    public static void main(String[] args) {
        Calculator calculator = new Calculator();
        System.out.println(calculator.add(1, 2));
    }
}
```

在项目根目录编译并运行：

```bash
javac -d out com/example/calculator/*.java
java -cp out com.example.calculator.Run
```

## 易错点

- `package` 声明必须放在文件顶部，否则编译报错
- 包名和目录结构必须一致，`com.example.calculator` 就要放在 `com/example/calculator/`
- 包名使用英文小写，不要使用中文包名
- 使用 `-d out` 编译时，javac 会自动按包名生成 `out/com/example/...` 的目录结构
- 运行带包的程序时，类名要写全限定名，例如 `com.example.calculator.Run`

## 练习与思考

1. 在 `基础概念/包的使用/` 下创建 `com/example/functions` 目录，把 `Run` 和 `Calculator` 类放进去并运行
2. 思考：为什么不同包里的两个 `Run` 类可以同时存在？
3. 试着在另一个包中 `import com.example.calculator.Calculator`，观察有什么效果

## 小结

- 包通过命名空间组织类，避免命名冲突
- 包名必须与目录层级对应
- 同包直接使用，跨包用 `import`
- 命令行运行带包程序要写全限定类名
