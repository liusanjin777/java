## 核心概念

### 方法与类

方法是写在类里的一段可复用代码，用来完成一个具体的操作。一个类可以包含多个方法；方法通常通过对象或类来调用。

### main 方法

`main` 是 Java 程序的入口，JVM 启动程序时会从这里开始执行。它的签名必须固定为：

```java
public static void main(String[] args)
```

### return 返回值

方法声明返回类型后，方法体内必须用 `return` 返回对应类型的数据。如果方法不需要返回数据，返回类型写 `void`。

## 代码示例

项目中的 [Run.java](../基础概念/函数类的使用/Run.java) 定义了两个类：

```java
package 函数类的使用;

public class Run {
    public int add(int a, int b) {
        return a + b;
    }
}

class Test {
    public static void main(String[] args) {
        Run run = new Run();
        int result = run.add(1, 2);
        System.out.println(result);
    }
}
```

执行流程：

1. `new Run()` 创建 `Run` 对象
2. `run.add(1, 2)` 调用方法，把 `1` 和 `2` 传给参数 `a`、`b`
3. 方法返回 `3`，赋值给 `result`
4. `System.out.println(result)` 打印结果

## 易错点

- `main` 方法签名必须完整，写成 `public static void main(String[] args)`，不要漏掉 `static` 或 `args`
- 有返回类型的方法必须写 `return`，返回类型为 `void` 时不要写 `return 值`
- 一个 `.java` 文件最多只能有一个 `public` 类，且文件名必须和这个 `public` 类名一致
- 当前示例用了中文包名，能运行但不推荐；后续练习建议使用英文小写包名，如 `basic.functions`

## 练习与思考

1. 给 `Run` 类加一个 `subtract(int a, int b)` 方法，并在 `main` 中调用，打印 `5 - 3` 的结果
2. 把 `add` 方法的返回类型改成 `void` 试试，看看会发生什么，思考为什么需要返回值
3. 思考：如果 `main` 里不写 `new Run()`，直接调用 `run.add(...)`，为什么编译会报错？

## 小结

- 方法是类中可复用的代码块，通常通过对象调用
- `main` 是程序入口，签名固定
- 有返回值的方法必须用 `return` 返回结果
- 一个文件只能有一个 `public` 类，文件名要与它一致
