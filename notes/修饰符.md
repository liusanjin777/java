## 核心概念

### 修饰符是什么

修饰符是加在类、方法、字段或局部变量前面的关键字，用来补充声明信息，例如控制访问范围、决定是否可变、是否属于类等。Java 的修饰符分为两类：可访问修饰符和非访问修饰符。

### 可访问修饰符

可访问修饰符有四个：`public`、`protected`、默认（不写）和 `private`，可见范围从大到小排列：

| 修饰符 | 同类 | 同包 | 子类（其他包） | 其他包 |
| --- | --- | --- | --- | --- |
| `public` | 可访问 | 可访问 | 可访问 | 可访问 |
| `protected` | 可访问 | 可访问 | 可访问 | 不可访问 |
| 默认（不写） | 可访问 | 可访问 | 不可访问 | 不可访问 |
| `private` | 可访问 | 不可访问 | 不可访问 | 不可访问 |

- `public`：谁都可以访问
- `protected`：同包可以访问，其他包只有子类可以访问
- 默认权限：只有同包可以访问，也叫包级可见
- `private`：只有本类内部可以访问，是封装的基础

`private` 和 `protected` 不能修饰外部类，外部类只能用 `public` 或默认权限。

### 非访问修饰符

非访问修饰符不控制可见范围，而是补充其他规则：

- `static`：修饰成员时表示该成员属于类，用类名直接访问，不需要创建对象
- `final`：修饰变量时不能重新赋值，修饰方法时不能被子类重写，修饰类时不能被继承
- `abstract`：修饰抽象类和抽象方法，抽象类不能直接创建对象，抽象方法必须由子类实现
- `synchronized`：同一时刻只允许一个线程进入该方法或代码块，用于多线程安全
- `volatile`：多线程下强制每次都从主内存读取字段，保证可见性
- `transient`：对象序列化时跳过该字段
- `native`：方法体由本地代码实现，Java 侧只写声明

`static`、`final`、`abstract` 是基础阶段最常用的三个非访问修饰符。

## 代码示例

示例代码在 `基础概念/修饰符/` 下。

### 可访问修饰符

`AccessDemo.java` 定义了四个不同权限的字段：

```java
package modifier;

public class AccessDemo {
    public int publicField = 1;
    protected int protectedField = 2;
    int packageField = 3;
    private int privateField = 4;

    public void showAll() {
        System.out.println("public=" + publicField);
        System.out.println("protected=" + protectedField);
        System.out.println("package=" + packageField);
        System.out.println("private=" + privateField);
    }

    public int getPrivateField() {
        return privateField;
    }
}
```

`SamePackage.java` 在同一个包中访问这些字段，`private` 只能通过公开方法读取：

```java
package modifier;

public class SamePackage {
    public static void main(String[] args) {
        AccessDemo demo = new AccessDemo();

        System.out.println(demo.publicField);
        System.out.println(demo.protectedField);
        System.out.println(demo.packageField);
        System.out.println(demo.getPrivateField());
    }
}
```

`DifferentPackage.java` 在其他包且不是子类，只有 `public` 可以直接访问；注释掉的三个成员访问如果取消注释会编译报错：

```java
package modifier.other;

import modifier.AccessDemo;

public class DifferentPackage {
    public static void main(String[] args) {
        AccessDemo demo = new AccessDemo();

        System.out.println(demo.publicField);

        // System.out.println(demo.protectedField);
        // System.out.println(demo.packageField);
        // System.out.println(demo.privateField);
    }
}
```

`SubClass.java` 在其他包但继承 `AccessDemo`，可以通过 `protected` 访问：

```java
package modifier.other;

import modifier.AccessDemo;

public class SubClass extends AccessDemo {
    public void useProtected() {
        System.out.println(protectedField);
    }

    public static void main(String[] args) {
        new SubClass().useProtected();
    }
}
```

### static 和 final

`StaticFinalDemo.java` 演示 `static` 字段、`static` 方法和 `final` 字段：

```java
package modifier;

public class StaticFinalDemo {
    public static int count = 0;
    public final String name;
    public static final double PI = 3.14;

    public StaticFinalDemo(String name) {
        this.name = name;
        count++;
    }

    public static void showCount() {
        System.out.println("共创建 " + count + " 个对象");
    }

    public static void main(String[] args) {
        StaticFinalDemo a = new StaticFinalDemo("A");
        StaticFinalDemo b = new StaticFinalDemo("B");

        StaticFinalDemo.showCount();
        System.out.println(StaticFinalDemo.PI);
        System.out.println(a.name + ", " + b.name);
    }
}
```

### abstract

`AbstractAnimal.java` 定义抽象类和抽象方法：

```java
package modifier;

public abstract class AbstractAnimal {
    public abstract void sound();

    public void eat() {
        System.out.println("动物在吃东西");
    }
}
```

`Dog.java` 继承抽象类并实现 `sound` 方法：

```java
package modifier;

public class Dog extends AbstractAnimal {
    @Override
    public void sound() {
        System.out.println("汪汪");
    }

    public static void main(String[] args) {
        Dog dog = new Dog();
        dog.sound();
        dog.eat();
    }
}
```

```bash

java -cp out modifier.SamePackage
java -cp out modifier.other.DifferentPackage
java -cp out modifier.other.SubClass
java -cp out modifier.StaticFinalDemo
java -cp out modifier.Dog
```

## 易错点

- 默认权限不是 `private`，同包的其他类可以访问
- `protected` 不是只给子类用的，同包内也能访问
- `final` 变量只能赋值一次；`final` 类不能被继承
- 抽象类不能 `new`，抽象方法必须在第一个具体子类中实现
- `static` 方法不能直接访问实例字段，实例字段需要对象才能使用
- `private` 字段需要公开方法（getter/setter）才能被外部读取
- 外部类不能用 `private` 或 `protected` 修饰，一个 Java 文件只能有一个 `public` 类

## 练习与思考

2. 在 `modifier.other` 中新建一个不继承 `AccessDemo` 的类，尝试访问 `protectedField`，观察编译结果

4. 思考：为什么一般把字段设为 `private`，再提供公开方法读写？

## 小结

- 可访问修饰符控制可见范围：`public` > `protected` > 默认 > `private`
- `static` 表示属于类，`final` 表示不可变，`abstract` 表示需要子类实现
- 尽量使用最小访问权限，能 `private` 就不 `public`，这是封装的思想
