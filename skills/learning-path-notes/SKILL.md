# 学习路径笔记生成

## 工作流程

1. **确认学习路径**
   - 先读取项目结构和已有笔记，识别用户当前学到哪个阶段。
   - 用户直接给出主题时，以用户描述为准；信息不足时基于目录和最近文件推断，不要反复追问。

2. **决定产出类型**
   - 新知识点：按模板创建一篇新笔记。
   - 已有笔记：增量更新对应章节，保留原有结构。
   - 阶段总结：生成一篇总结型笔记，并更新 `notes/README.md` 索引。

3. **生成笔记**
   - 使用 [assets/note-template.md](assets/note-template.md) 作为骨架。
   - 笔记统一写入项目根目录的 `notes/`，文件名为 `notes/<主题>.md`，中文主题名直接使用，例如 `notes/函数的使用.md`。
   - 内容使用中文；代码示例与项目中的代码保持一致。
   - 结合项目里的真实代码举例，不要编造与当前学习内容无关的示例。

4. **收尾**
   - 检查 Markdown 标题层级：一篇笔记只有一个一级标题。
   - 若 `notes/` 下已有超过一篇笔记，更新 `notes/README.md` 的目录列表。
   - 用简短一句话告知用户笔记路径和覆盖内容。

## 笔记结构

每篇笔记按模板包含：

- 主题标题与日期
- 学习目标
- 核心概念
- 代码示例
- 易错点
- 练习与思考
- 小结
- 下一步

对较长的主题，使用 `##` 分节，避免把所有内容堆在一个章节里。
